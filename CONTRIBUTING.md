# Contributing

## Get started
To make any code changes, you first need to fork this repo and clone it on your local machine. Note: your machine MUST be a mac. Only Macs can run Xcode.

Next, you must [install Xcode](https://developer.apple.com/xcode/), and sign in using your Apple ID. 
Due to Apple capability restrictions, unless you have a paid developer account, some features will not work on your local clone, such as WeatherKit, or push notifications.

After that, you are able to start developing. Before you build the product to your phone or a simulator, you must configure the signing, 
which can be found in the Signing & Capabilities section on the main app target. 

Finally, you can build, test, and when OK, you can make a PR and make your changes live!
> [!IMPORTANT]
> In order to test your app changes on a device or simulator, you must have the paid Apple Developer account. The app uses WeatherKit and other capabilities that only work in testing if you have a paid Apple Developer account :(

## Localizations
Localizations are a part of the app that anyone can contribute to without an Apple Developer subscription. In BlueWatch v1.4.2, localizations are introduced. Depending on your system language, the app will use that language. However, the app is not localized for all languages. To help add new translations/improve existing ones, you can look at the [Localizable.xcstrings](BlueWatch/Localizable.xcstrings) file, where you'll see numerous objects that look like this:
```
"Get Watch Connection" : {
    "comment" : "Intent to check if the watch is connected.",
    "isCommentAutoGenerated" : true,
    "localizations" : {
      "fr" : {
        "stringUnit" : {
          "state" : "machine_translated",
          "value" : "Obtenir l’état de connexion de la montre"
        }
      }
    }
  },
```
Look for the string you want to translate, and add a new language object inside the localizations object:
```
"Get Watch Connection" : {
    "comment" : "Intent to check if the watch is connected.",
    "isCommentAutoGenerated" : true,
    "localizations" : {
      "fr" : {
        "stringUnit" : {
          "state" : "machine_translated",
          "value" : "Obtenir l’état de connexion de la montre"
        }
      },
      "new_language" : {
        "stringUnit" : {
          "state" : "translated",
          "value" : "translation in the new language"
        }
      }
    }
  },
```

You can do this for as many strings as you need. Changing an existing translation is very similar, simply change the `value` string inside the language object.

Also refer to this [list of language codes](https://simplelocalize.io/data/locales/) to find the right language ID (eg. 'fr' -> 'french').

Once completed, open a pull request!
